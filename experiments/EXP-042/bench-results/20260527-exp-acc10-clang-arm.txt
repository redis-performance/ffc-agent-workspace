# iterations per float the savings compound to -3.46 c/f (-8.2%) on random.
# Canada shows only -1 i/f, suggesting ~1 exponent digit on average there.
# GCC was already using shift-add scheduling; macro fall-through is identical.
#
# Decision: ACCEPTED
