# Key observations:
#
# 1. i/f INCREASES on canada (+4.9) and mesh (+1.9): expected — shift-add emits 2 instructions
#    per accumulation vs 1 `mul` instruction. With ~5 integer/fraction accumulations per canada
#    float, +5 i/f per float is consistent.
#
# 2. c/f DECREASES: canada −2.2% c/f, random −1.4% c/f. The shift-add chain is 2 cycles
#    vs Clang's mul-based 4-cycle recurrence (smaddl 3c + sub 1c). Serial digit accumulation
#    chains are cut from 4-cycle to 2-cycle per level.
#
# 3. Constraint choice (`=r` not `=&r`): with `=&r` (early-clobber), the compiler allocates a
#    separate result register and inserts `mov acc, result` after the asm block — +2 extra i/f
#    per accumulation. With `=r`, the compiler can allocate the result in the same register as
#    `acc` (%2), achieving true in-place update: 2 instructions total per accumulation, no mov.
#
# 4. GCC preserved: the `#else` branch expands FFC_DIGIT_ACC10(acc, d_expr) to
#    `((acc) * 10 + (uint64_t)(d_expr))` — identical to the original expression. GCC sees
#    the same code as before and generates its natural shift-add sequence.
#
# Decision: ACCEPTED — +2.2% canada ≥ 2% threshold, GCC unchanged.
